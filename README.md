# SQL Revenue Analytics Project

## Overview
This project analyzes e-commerce transactional data using SQL to uncover revenue trends, customer behavior, and product performance insights.

## Tools
- SQL (SQLite)
- RStudio
- Tableau
- GitHub Copilot

## Key Business Questions
- Which products generate the most revenue?
- Who are the highest-value customers?
- How does revenue trend over time?
- Which markets perform best?
